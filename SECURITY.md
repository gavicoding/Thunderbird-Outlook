# Security Policy

## Reporting a Vulnerability

If you discover a security or data-integrity issue (for example, path traversal via crafted email headers or unsafe SQLite/COM handling), please **do not** open a public issue with exploit details.

Instead, report it privately via **GitHub Security Advisories** on this repository or email `gavicoding@gmail.com` with:

- A description of the issue and potential impact
- Steps or sanitized sample payloads to reproduce it

We will review reports promptly and coordinate a fix before public disclosure.
